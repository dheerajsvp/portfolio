TripSplit

Splits group trip expenses, then works out the fewest payments needed to settle up.

  • A greedy two-heap algorithm cuts a group’s debts to at most n−1 payments. Money is stored as integer paise, so rounding never drifts.
  • UPI deep links and generated QR codes make settling a one-tap job. I tested them with real transactions across several UPI apps.
  • 75 automated tests (Django and Vitest) run in GitHub Actions CI. The API runs on Render and the front end on Vercel, connected over CORS.

Ask Your Documents

Answers questions from uploaded PDFs and cites the page each answer came from.

  • Retrieval-augmented generation over document chunks stored in PostgreSQL with pgvector. When the answer isn’t in the document, it says “not found” instead of guessing.
  • PDF parsing and embedding run as Celery and Redis background jobs, so uploads return in about 0.3 s. Jobs are safe to run twice, retries are race-safe, and a Redis outage shows as a failed status with a retry button.
  • Model citations are verified in code, and the pipeline is hardened against prompt injection from document text.
  • An evaluation script measures retrieval quality. Shipped with 133 backend and 98 frontend tests, a Docker Compose stack and an axe-core accessibility audit with 0 violations.
